GPU Store

A real-time marketplace for buying/selling GPU compute.

speed

Matchmaking latencies measured in microseconds

STACK: C++, CMake, Python, pybind11, HTML/CSS/JS
link GITHUB REPO

This project was built over seven weekends. The C++ was handwritten to make the repository a direct sample of my own coding ability; in production work, I use AI tooling where it improves productivity.

The UI is intentionally utilitarian - the project focused on backend systems and C++, not frontend polish, and coding agents at the time were considerably weaker at UI development.

This project is an MVP focused on the marketplace workflow. It does not provision or deliver GPU compute or process payments.
