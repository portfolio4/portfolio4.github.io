AI Food Kiosk with FPGA Bypass

Speak with an AI agent in real time to order food.

record_voice_over

A voice-ordering agent with FPGA pattern matching for supported requests.

STACK: SystemVerilog, cocotb, C++, HTML/TailwindCSS/JS, Whisper, Codex App-Server
link GITHUB REPO

A voice-ordering prototype that uses Whisper for speech recognition and a Codex agent for conversational responses. Orders are recorded in a local cart; the prototype does not send orders to a restaurant for fulfillment.

I implemented a request-matching path in SystemVerilog running on a Basys3 FPGA board. The FPGA receives Whisper's transcribed text and matches it against preconfigured patterns. For example, the user's transcribed request, "can i get a classic cheeseburger please", matches the preconfigured pattern "get a classic cheeseburger" on the FPGA. This match produces a JSON command instructing the UI to add one Classic Cheeseburger to the cart. Supported requests bypass the Codex agent without waiting for an LLM response.
